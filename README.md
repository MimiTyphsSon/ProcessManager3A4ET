# Вариант 01. Диспетчер запущенных процессов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Процессы, Process, async/await, SemaphoreSlim, DLL, P/Invoke, IDisposable

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Получить список процессов через Process.GetProcesses().
2. Вывести PID, имя и доступную информацию о процессе; обработать недоступные свойства.
3. Добавить запуск программы через Process.Start с безопасной передачей аргументов.
4. Вынести сбор информации в отдельный сервис и не блокировать UI/основной поток.
5. Ограничить параллельный сбор сведений через SemaphoreSlim.
6. Корректно освобождать Process и обрабатывать завершение процесса во время чтения.
7. Вынести сервис в Class Library и получить PID приложения через P/Invoke.

## Дополнительные задания
8. Сохранять последние пути запуска в HKCU.
9. Добавить журнал действий с временными метками.
10. Добавить тайм-аут ожидания внешнего процесса.
11. Добавить тесты на пустой список и недоступный процесс.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
